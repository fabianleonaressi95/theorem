# Sangaku Geometry — Circle-Construction Classification

**Working title:** *Sangaku Geometry: A Classification of Circle Configurations by Symmetry Groups and Algebraic Distance Fields*

Independent geometry workstream within THEOREM. It starts from source-verified Sangaku problems and develops a reproducible classification protocol for finite configurations generated by circle/line intersections, circumcircle constructions and tangency constraints.

## Scientific status
- **PROVED:** quadratic-tower theorem for finite sequences of line-line, line-circle and circle-circle intersections over a characteristic-zero subfield of R.
- **EXACT:** normalized Vesica Piscis and regular-pentagon field calculations.
- **MODEL:** three-circle tangency identity. Its identification with a particular 1837 Sangaku diagram is not historically verified.
- **OPEN:** complete invariants, classification of Apollonian/tangency constructions, and a verified historical Sangaku corpus.

## Reproduce
Python 3.10+, SymPy and pytest:
    python -m pip install sympy pytest
    python -m pytest -q research/sangaku_geometry/tests
    python research/sangaku_geometry/symbolic_checks.py

No numerical fitting is used in the exact identities. Geometric symmetry groups are not identified with Galois groups without a separately proved action.
