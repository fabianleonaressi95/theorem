# Case SGC-003 — Equal-radius tangency model

**Status:** MODEL / EXACT-COMPUTATION; historical attribution unverified.

For
\[
r_1=(r^2-x^2)/(2r),\quad
r_3=-r_1+\sqrt{r_1^2+x^2},\quad
r_4=(r^2+x^2)/(2r)-r_1,
\]
the positive-root identity gives
\[
r_3=r_4=x^2/r.
\]
At x/r=1/3, r1/r=4/9 and r3/r=r4/r=1/9.

This sheet certifies only the algebra written above. The corresponding configuration is transcribed on the secondary Cut-the-Knot page, which says that its applet “purports to suggest” an 1837 Aichi Sangaku and cites *Temple Geometry* 1.5.7. That is not a primary tablet image.

**Source-audit correction:** do not identify this model with the 1837 Ohsu Kannon Problem 16 in Fukagawa–Rothman (2008), Figure 4.15, p. 101. That published problem has four equal circles inside a larger circle and auxiliary p/q circles; its tangency graph is different. See [SOURCE_AUDIT_1837.md](../SOURCE_AUDIT_1837.md). The exact 1989 *Temple Geometry* 1.5.7 page and the original tablet/archival photograph remain to be inspected before any stronger historical attribution.
