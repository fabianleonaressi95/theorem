# Bibliografia generale

Catalogo centrale delle fonti RGS–PSU–PRISM–Q6. Le pubblicazioni esterne, le monografie, i manoscritti interni, i risultati numerici e le fonti non standard sono registrati separatamente.

Stati: **VERIFICATA** (metadati controllati); **IDENTIFICATA** (titolo/autori recuperati, dettagli mancanti); **DA DISAMBIGUARE** (riferimento incompleto); **CONTESTO** (fonte storica, critica o non standard).

## Regola
Ogni voce deve riportare titolo, autori, anno, sede, DOI/URL, uso previsto nel progetto e stato di verifica. Una fonte citata non prova automaticamente il modello interno. Non inventare metadati mancanti.
