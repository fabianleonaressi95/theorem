# C60–Kathara–Q6 bridge: exact homology and factorization obstruction

**Status:** exact rational homology of all three declared complexes is computed. The existing Kathara→Q6 map has a non-degenerate Gate D implementation in the companion repository. A C60→Kathara map and a Stone–Wales intertwiner remain open.

## 1. Exact homology of the three complexes

The audit rebuilds the integer boundary matrices using the canonical incidence conventions from companion repository commit 99ea9b9e4cb42d683073e02b64e8d94b9f144968 and computes their ranks over \(\mathbb Q\).

| Complex | \((C_0,C_1,C_2)\) | \((\operatorname{rank}B_1,\operatorname{rank}B_2)\) | \((\beta_0,\beta_1,\beta_2)\) | \(\chi\) |
|---|---:|---:|---:|---:|
| C60 fullerene sphere | (60,90,32) | (59,31) | (1,0,1) | 2 |
| Kathara filled planar complex | (12,21,10) | (11,10) | (1,0,0) | 1 |
| Q6 cubical 2-skeleton | (64,192,240) | (63,129) | (1,0,111) | 112 |

All three satisfy \(B_1B_2=0\). The Q6 1-skeleton has cycle rank 129, but after attaching its 240 square faces its first homology is zero. Its 2-skeleton has \(\beta_2=111\); the missing 3-cells of the full 6-cube would kill those 2-cycles.

The Kathara 2-cells are the ten bounded planar regions specified by the source transcription. This is a declared cellular convention; it is not an assertion that the drawing itself uniquely determines physical 2-cells.

## 2. A real obstruction: the Kathara factorization kills the C60 sphere class

C60 has \(H_2(C60;\mathbb Q)\cong\mathbb Q\), generated by its oriented spherical fundamental class. The filled Kathara complex is a disk and has \(H_2(K;\mathbb Q)=0\).

Therefore **every** chain map
\[
P:C_*(C60)\longrightarrow C_*(K)
\]
induces the zero map on second homology:
\[
H_2(P):H_2(C60;\mathbb Q)\longrightarrow H_2(K;\mathbb Q)=0.
\]
Consequently every composite
\[
C60\xrightarrow{P}K\xrightarrow{R}Q6
\]
kills the C60 fundamental class, regardless of the detailed integer entries of P and R. This is a genuine homological obstruction to a sphere-class-preserving bridge **through this Kathara disk**.

It does not rule out an arbitrary chain map C60→Kathara, nor does it rule out a direct C60→Q6 chain map. It says that a nonzero H2 image cannot survive the intermediate Kathara complex.

## 3. The existing Kathara→Q6 map is more developed than the old audit assumed

The companion repository contains two explicit constructions:

- Gate C: a valid integral chain map with \(R_2=0\), which collapses all ten Kathara faces.
- Gate D: a non-degenerate integral face lift. It maps source edges to shortest Q6 paths using the declared axis order \((1,2,0,3,4,5)\), then fills face loops by exact cubical square swaps. Its implementation checks
\[
B_1^{Q6}R_1=R_0B_1^K,\qquad
B_2^{Q6}R_2=R_1B_2^K
\]
as integer matrix identities, and certifies \(\operatorname{rank}R_2=10\) modulo 1,000,003.

Sources:
- companion code: src/kathara_q6_chain_map.py and src/kathara_q6_nondegenerate_chain_map.py;
- companion definitions: src/kathara_cellular_complex.py and src/q6_complex.py;
- Gate C and Gate D specifications: docs/KATHARA_Q6_CHAIN_MAP_GATE_C.md and docs/KATHARA_Q6_NONDEGENERATE_GATE_D.md.

The Gate D axis order is a declared combinatorial convention, not a result derived from the RGS metric. Full rank of R2 on chain groups does not make the map injective on homology: the source Kathara disk still has H2=0.

## 4. What a C60→Kathara map would require

A candidate integer chain map would have matrices
\[
P_0\in\mathbb Z^{12\times60},\quad
P_1\in\mathbb Z^{21\times90},\quad
P_2\in\mathbb Z^{10\times32}
\]
satisfying
\[
B_1^K P_1=P_0B_1^{C60},\qquad
B_2^K P_2=P_1B_2^{C60}.
\]
The dimensions alone do not select P. A reproducible construction needs a declared assignment of C60 cells to Kathara cells, an orientation convention, and a stated map category (cellular map, subdivision, quotient, or abstract chain map). A least-squares fit or visual alignment is not sufficient.

Even if such P is found, the homology calculation above proves that its induced map on H2 is zero. If the scientific objective requires preserving the fullerene sphere class, the intermediate target must be changed from the filled Kathara disk to a complex with nontrivial H2, or a direct C60→Q6 map must be studied.

## 5. Stone–Wales intertwining remains a separate condition

Let \(S_i:C_i(C60)\to C_i(C60')\) be the existing local Stone–Wales chain correspondence. To claim compatibility with a Q6/Kathara action, one must define an action \(A_i\) on the target and a post-switch map \(P_i'\), then verify the typed commuting condition
\[
P_i'S_i=A_iP_i.
\]
No such target action is currently defined. The 30-move \(I_h\) orbit classification does not supply it automatically.

## 7. Additional exact obstruction from bipartite parity

The direct C60 carbon graph contains pentagonal 5-cycles. The Q6 1-skeleton is the 6-cube graph and is bipartite. Since a graph homomorphism sends a cycle to a closed walk of the same length and a bipartite graph has no closed odd walk, there is no edge-preserving graph homomorphism from the C60 carbon graph to the Q6 1-skeleton.

This is narrower than a chain-map obstruction: it rules out only a vertex map taking every C–C bond to one Q6 edge. It does not rule out a cellular chain map with multi-edge images, subdivision, common refinement, or a face-fibre representation map. Thus the direct chain-map problem remains open, but the naive vertex-to-state/edge-to-edge identification is mathematically excluded.

The existing pristine-C60 representation audits must also remain distinct from the Stone–Wales problem: the tested A4 face-tangent representations have a character mismatch, while a separately specified V4 restriction admits an abstract 64D intertwiner. The post-SW carbon graph has a combinatorial V4 automorphism group, but no geometrically realized post-SW face-tangent action has yet been matched to the Q6 V4 action.
