# GL(6,2)-affine coordinate-mixing audit on the Q6 Walsh filtration

**Date:** 2026-11-24
**Status:** finite algebraic audit. No multifractal, spectral-dimension,
or physical claim. Companion to
`docs/QUANTUM_FRACTAL_Q6_WALSH_FILTRATION_AUDIT.md` (PR #435 lineage).

## 1. Question

Which affine maps `T(x) = Px ⊕ b` on `Q6 = F_2^6` (64 states) fail to
preserve the prefix conditional expectations `E_j`, and what do their
commutator profiles look like?

## 2. Exact criterion (verified, 0 mismatches / 500 matrices)

For `P ∈ GL(6,2)` and `j = 1,…,5`:

```
[U_T, E_j] = 0   iff   P[0:j, j:6] = 0
```

i.e. the top-right `j × (6−j)` block of `P` vanishes. Equivalently,
the first `j` rows of `P` must be supported on the first `j`
coordinates. `P` preserves the *whole* flag iff `P` is lower
triangular. The translation `b` never affects the sigma-algebra —
verified: all sampled `b` give the zero profile.

For permutation matrices `P ∈ S6` this reduces to the setwise
criterion of PR #435; for general `P ∈ GL(6,2)` the block criterion is
the correct generalization (row-span formulation).

## 3. Enumerated classes

| class | size | result |
|---|---|---|
| pure translations `b ∈ F_2^6` | 64 sampled | **all preserve every `E_j`** |
| coordinate permutations `S6` | 720 exhaustive | 51 distinct profiles; only identity preserves all levels |
| trigram blocks `GL(3,2)×GL(3,2)` | 28,224 exhaustive | 16 distinct profiles; commutator **exactly zero at j=3** for every element (trigram boundary preserved); 64 elements preserve the full flag |
| elementary transvections | 30 | 15 preserve the full flag — precisely the lower shears `E_{ij}`, `i>j` |
| companion cycles | 2 | full nonzero profile at j=1,…,5 (strongest mixing found) |
| random `GL(6,2)` sample | 20,000 (seed 20261124) | 45 distinct profiles; 95.7% first break at j=1; only 3 preserve the full flag |

`|GL(6,2)| = 20,158,709,760` — exhaustive enumeration infeasible;
natural classes plus fixed-seed sample used instead.

## 4. Naturally distinguished operators (requirement 5–6)

**Yes — one exists, with provenance.** The graph automorphism group of
the binary Hamming graph `Q6 = H(6,2)` is `Aut = S2 wr S6`
(order 46,080), proved in `theorems/EQC-4-hamming-automorphism-clifford.md`
and generated by the EQC language maps in `models/eqc_automorphism.py`.
Its linear parts are exactly the `P ∈ S6`; its translations are the bit
flips.

Two named generators have nontrivial, provenance-backed profiles:

- `ROT` (order `(5,1,2,3,4,0)`): first nonzero commutator at `j=1`;
  Walsh block Frobenius norms `1.0, 1.414, 2.0, 2.828, 4.0` at
  `j = 1,…,5`.
- `REV` (order `(5,4,3,2,1,0)`): first nonzero at `j=1`; Walsh block
  norms `1.0, 1.732, 2.646, 3.464, 4.0`.

These are **graph automorphisms**, not arbitrary matrices — but they
are still classical relabellings, not derived dynamics. No stored NPZ
operator realizes genuine `GL(6,2)` mixing beyond permutations; the
companion-cycle and generic-`GL` profiles are algebraic
counterexamples only.

The trigram block class is the algebraic shadow of the two-trigram /
Anti-Twin structure (`Pi_AT` flips columns 3,4,5): block maps preserve
the `j=3` filtration level *exactly*, so the Walsh audit can resolve
trigram-boundary-preserving vs trigram-mixing operators.

## 5. Non-conclusions

- Nonzero commutators are **not** multifractality, not a spectral
  dimension, not a physical coupling.
- The Borel (lower-triangular) subgroup of order `2^15 = 32,768`
  preserves the full flag; its cosets produce the observed profiles.
- Minimal structure needed for a *physically derived* coordinate-mixing
  operator: a stored/declared operator on the 64-site space that is not
  a graph automorphism — e.g. a weighted Hodge/Laplacian block or a
  PRISM-induced linear map with provenance. None was found in
  `data/RGS_PSU_all_matrices.npz`.
