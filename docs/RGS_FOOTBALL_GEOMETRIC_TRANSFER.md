# Geometry-derived RGS → football transfer

The source geometry is the recovered 64-point RGS coordinate table
`data/rgs_188d/X_Oh_reconstructed.csv`. The target is the actual 92-node
truncated-icosahedron shell generated by `build_football_shell()`: 60
truncated-icosahedron vertices and 32 panel centres.

For each source and target point, use its radial unit direction. At each
target direction \(n\), select the nearest source directions \(n_i\) and
solve the minimum-norm constrained interpolation problem
\[
\min_w\|w\|_2^2,\qquad
\sum_iw_i=1,\qquad \sum_iw_in_i=n.
\]
The solution is
\[
w=C^T(CC^T)^+d,\quad C=[\mathbf1; n_i^T],\quad d=[1;n].
\]
The 92 scalar weights are lifted to Cartesian vector fields as
\(W=W_s\otimes I_3\), giving \(W\in\mathbb R^{276\times192}\).
The shell tangent projector then removes the component normal to each
node's area-weighted averaged surface normal. The resulting transfer is
geometry-derived and reproducible, not a one-to-one identification of sites.

Run:
`python scripts/build_rgs_football_geometric_transfer.py`
and
`python -m pytest -q tests/test_football_quaternion_bridge.py`.

Interpretation limits: this map reproduces constant vector fields and radial
direction coordinates by construction. It does not automatically preserve
the RGS stiffness operator, quaternionic group action, or physical energy.
The next spectral test must transfer an actual RGS three-dimensional
eigenspace, project it into the shell tangent space, and compare it with
shell eigenmodes using principal angles. A small angle would be a numerical
alignment candidate, not proof of a common physical mode.
