# THEROEM — Mathematical theorem programme

Questo repository raccoglie dimostrazioni matematiche, una per volta, per il programma RGS–PSU–PRISM–Q6 e i suoi collegamenti geometrici e fisici.

## Regole di lavoro

1. **Un solo teorema per volta.** Ogni risultato ha enunciato, ipotesi, dimostrazione completa e conseguenze.
2. **Niente workflow giganteschi.** Nessuna pipeline automatica, matrice di script o serie di PR per attività accessorie.
3. **Niente codice come sostituto della prova.** Il nucleo del lavoro è matematico. Calcoli numerici sono ammessi solo come verifica supplementare e dichiarata.
4. **Nessuna conclusione più forte delle ipotesi.** Distinguere sempre teorema dimostrato, risultato condizionale, evidenza numerica, congettura e problema aperto.
5. **Fonti pertinenti.** Gli articoli e i risultati degli autori citati entrano solo se sostengono un passaggio preciso della dimostrazione.
6. **Nessuna ripetizione di audit già conclusi.** Si riutilizzano risultati e dati esistenti, verificandoli solo quando sono indispensabili.

## Scheda standard di ciascun teorema

- Enunciato preciso
- Definizioni e ipotesi
- Lemmi necessari
- Dimostrazione, con ogni implicazione giustificata
- Ipotesi non eliminabili e casi limite
- Corollari per RGS–PSU–PRISM–Q6
- Riferimenti bibliografici, con indicazione esatta di ciò che dimostrano
- Stato: dimostrato / condizionale / congettura / aperto

## Indice

I teoremi saranno aggiunti singolarmente in `theorems/`, numerati nell'ordine effettivo della dimostrazione. Nessun teorema viene dichiarato dimostrato sulla base di una simulazione o di un'identificazione formale non provata.
