# Registro delle evidenze

Ogni affermazione rilevante va registrata con fonte, tipo di evidenza e ambito:
- PROVA MATEMATICA
- VERIFICA NUMERICA
- RISULTATO SPERIMENTALE
- RISULTATO PUBBLICATO
- CANDIDATO / IPOTESI
- NON VERIFICATO

Non trasferire una conclusione da un settore a un altro senza dimostrare il ponte.
