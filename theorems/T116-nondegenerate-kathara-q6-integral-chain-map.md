# T116 — Non-degenerate integral Kathara-to-Q6 chain map

**Classification:** finite combinatorial result with exact integer chain identities and a modular rank certificate. The map is valid for the explicitly declared vertex chart and axis-order convention; it is not claimed to be RGS-metric canonical or unique.

## 1. Source and target complexes

Let K be the explicit 12-vertex, 21-edge, 10-face Kathara cellular complex used by the source implementation. Let X be the standard cubical six-cube, whose 1-skeleton is Q6 and whose 2-skeleton has 64 vertices, 192 edges and 240 square faces.

Write the integer boundary maps as B_1^K,B_2^K and B_1^X,B_2^X. The target Q6 bit convention is the repository's fixed big-endian indexing (axis 0 is the most significant bit).

The source vertex chart is the already-declared map
\[
g:V(K)\longrightarrow V(Q_6),
\]
implemented by \`kathara_vertex_to_q6_label\`. It is injective on the 12 source vertices.

## 2. Deterministic chain maps

Define R_0 as the one-hot vertex map induced by g. For each canonically oriented source edge (u,v), u<v, define its image under R_1 to be the shortest Q6 path between g(u) and g(v), traversing differing bit axes in the fixed order
\[
\mathrm{AXIS\_ORDER}=(1,2,0,3,4,5).
\]
If a source face boundary traverses a canonical source edge backwards, use the exact reverse of that edge's path word.

For each source face, concatenate its oriented edge path words. This is a closed Q6 word. Sort adjacent axis inversions by swapping two distinct commuting bit flips. Each swap changes the path by the boundary of one elementary Q6 square. Equal adjacent flips cancel as a backtrack. The signed sum of the recorded squares defines the corresponding column of R_2.

Thus
\[
R_0\in\mathbb Z^{64\times12},\quad
R_1\in\mathbb Z^{192\times21},\quad
R_2\in\mathbb Z^{240\times10}.
\]

## 3. Finite chain-map theorem

For the above fixed chart, edge-path convention and square-swap filling algorithm, the resulting integer matrices satisfy
\[
\boxed{B_1^X R_1=R_0B_1^K,\qquad
B_2^X R_2=R_1B_2^K.}
\]
Moreover,
\[
\boxed{\operatorname{rank}_{\mathbb Q}R_2=10.}
\]
Hence the induced map on the source 2-chain group is injective.

### Proof / certificate

The first identity follows because the boundary of each oriented Q6 edge path is its terminal vertex minus its initial vertex, exactly the image under R_0 of the source edge boundary.

For each source face, the concatenated edge word is closed. A swap of adjacent distinct axes replaces one two-edge route around a coordinate square by the other route; their difference is the oriented boundary of that square. Cancelling equal adjacent flips leaves the empty word. Summing the recorded oriented square boundaries therefore gives exactly the original mapped face-boundary word. This proves the second chain identity.

For the finite matrices produced by the declared algorithm, the source audit checks both identities by exact integer-array equality. It also computes rank R_2 modulo the prime p=1,000,003 and obtains rank 10. A 10-by-10 minor nonzero modulo p has integer determinant not divisible by p, hence is nonzero over Z and Q. Since R_2 has exactly 10 columns, its rational rank is exactly 10. The source test verifies that every face column is nonzero. \(\square\)

The modular rank check is a certificate for the finite integer matrix generated by the algorithm; it is not a proof that every alternative axis ordering has the same rank.

## 4. Geometric scope and non-claims

- **Established:** exact integral chain-map identities for the declared finite map; full column rank of R_2; nonzero square filling for every source face.
- **Convention-dependent:** the fixed axis order is a deterministic combinatorial choice selected by the finite rank audit. It is not derived from the RGS metric and is not claimed canonical.
- **Coordinate attachment:** the 12 mapped vertices are attached to the recovered RGS seed through its hash-verifying loader; all 21 source edges have positive RGS chord length.
- **Open:** RGS-metric canonicality, cellular embedding, equivariance under the actual symmetry subgroup, a justified lift to the Ellis hypersurface, compatible SU(2) edge transport, and any supergolden three-channel intertwiner.
- **Not implied:** a torsion or Pin structure, a continuum limit, or a physical identification of the Kathara cells.
