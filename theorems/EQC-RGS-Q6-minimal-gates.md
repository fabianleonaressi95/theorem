# Minimal native EQC gates for the RGS-induced Q6 subgroup

**Classification:** exact finite combinatorial result and explicit permutation-basis realization in the six-qutrit EQC reference simulator; not a hardware implementation claim.

## Encoding

The existing RGS audit fixes the ordered 64-point seed and identifies its labels with Q6 vertices \(v\in\{0,1\}^6\). The repository's established mapping stores Q6 bit \(i\) in EQC register \(q_i\). Binary symbols 0 and +1 are qutrit digits 1 and 2; digit 0 (symbol -1) lies outside the Q6 subspace.

A binary flip must swap digits 1 and 2 while fixing digit 0. EQC instruction: \`P qN 0 2 1\`. The cyclic qutrit shift X is not Q6-preserving.

## Three generators

The induced order-16 RGS/Q6 group is generated by:
- \(A_x\): \`P q2 0 2 1\` (toggle Q6 bit 2);
- \(B_y\): \`P q1 0 2 1\` (toggle Q6 bit 1);
- \(S_{yz}\): \`SWAP q0 q1\` followed by \`SWAP q3 q4\` (exchange bit pairs (0,1) and (3,4)).

The subgroup generated by \(B_y,S_{yz}\) is \(D_4\) of order 8; \(A_x\) is an independent commuting \(C_2\). Therefore the generated group is \(C_2\times D_4\), order 16.

Three is the minimal number of abstract group generators: the Frattini quotient of \(C_2\times D_4\) is \(C_2^3\), so its generator rank is 3. This is a group-generator lower bound, not a hardware gate-depth bound.

## Anisotropic reference conductances

For fixed MQM-1 reference vector \(x_*\in\mathbb R^{192}\), the same-action symmetry preserving the RGS embedding is
\[
G_{\rm RGS-MQM}(x_*)=
G_{\rm RGS-Q6}\cap\operatorname{Stab}_{\operatorname{Aut}(Q_6)}(x_*).
\]

For direction-only values \(c_0,\ldots,c_5\):
- all equal: stabilizer order 16;
- all distinct: order 8 (the three independent RGS-induced bit translations);
- \(c_0=c_1\) and \(c_3=c_4\): paired coordinate exchange survives, order 16;
- generic edgewise-distinct values: order 1.

The exact general answer is the finite edge-permutation stabilizer, not a universal order. Equality is exact on supplied values; use stored/calibrated values, not rounded display values.

## Verification boundary

The standard-library audit reconstructs the existing RGS seed, derives the three generators, verifies their generated group equals the complete 16-element RGS/Q6 subgroup, verifies their action on all 64 Q6 basis states, checks bijectivity on all 729 qutrit basis states, and computes anisotropic stabilizers.

Run: \`python -m unittest tests.test_eqc_rgs_q6_gates -v\`.

**Established:** exact finite group generation, Q6-subspace preservation, and permutation-unitary semantics in the six-qutrit computational basis.

**Not established:** hardware compilation, gate-depth optimality, physical calibration of \(x_*\), or quantum speedup.
