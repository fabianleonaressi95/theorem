# T026 — McKay–E₈ recurrence for all nine 2I multiplicities

**Status:** exact representation-ring recurrence and exact-arithmetic audit. This computes every irreducible multiplicity in \(\operatorname{Sym}^m(\mathbb C^2)|_{2I}\) without constructing 120 group matrices or numerically integrating characters.

**Base:** T025, branch `t025-rumin-middle-degree-blocks`.  
**Group:** binary icosahedral group \(2I\subset SU(2)\), order 120.  
**McKay graph:** affine \(E_8\), with the defining two-dimensional spin representation at the neighbor of the trivial node.

## 1. Labelled McKay graph

Use the following ordered list of nine irreducibles:
\[
(\mathbf1,2_s,3,4_s,5,6_s,4,2'_s,3').
\]
Their dimensions are
\[
d=(1,2,3,4,5,6,4,2,3),\qquad
\sum_i d_i^2=120,\quad \sum_i d_i=30.
\]
The affine \(E_8\) graph has edges
\[
\mathbf1-2_s-3-4_s-5-6_s-4-2'_s,
\qquad 6_s-3'.
\tag{1}
\]
Here \(2_s,4_s,6_s,2'_s\) are the four spinorial irreducibles; the other five descend to irreducibles of the rotational icosahedral group.

Let \(A\) be the symmetric adjacency matrix of (1). The dimension vector obeys
\[
Ad=2d,
\]
which is the dimension identity for tensoring every irreducible with the defining two-dimensional representation.

## 2. Exact recurrence

Write
\[
V_m=\operatorname{Sym}^m(\mathbb C^2)|_{2I}
=\bigoplus_{i=0}^{8} n_i(m)\rho_i,
\qquad n(m)=(n_0(m),\ldots,n_8(m))^T.
\]
The Clebsch–Gordan identity for \(SU(2)\),
\[
\mathbb C^2\otimes\operatorname{Sym}^m(\mathbb C^2)
\simeq\operatorname{Sym}^{m+1}(\mathbb C^2)
\oplus\operatorname{Sym}^{m-1}(\mathbb C^2),
\]
restricts to \(2I\) and gives
\[
\boxed{n(0)=e_{\mathbf1},\quad n(1)=e_{2_s},\quad
n(m+1)=A n(m)-n(m-1).}
\tag{2}
\]
Thus the nine multiplicities are integers generated by a fixed 9×9 integer matrix. This is an exact representation-ring computation, not a floating-point character approximation.

Two structural checks hold for every \(m\):
\[
\sum_i d_i n_i(m)=m+1,
\tag{3}
\]
and, since the central element \(-I\in2I\) acts on \(V_m\) as \((-1)^m\), even \(m\) contain only the five nonspinorial nodes while odd \(m\) contain only the four spinorial nodes.

## 4. Independent invariant-sector check

The invariant multiplicity \(n_{\mathbf1}(m)=\dim V_m^{2I}\) is also checked against the classical binary-icosahedral invariant Hilbert series
\[
\sum_{m\ge0}n_{\mathbf1}(m)t^m
=\frac{1-t^{60}}{(1-t^{12})(1-t^{20})(1-t^{30})}
=\frac{1+t^{30}}{(1-t^{12})(1-t^{20})}.
\tag{4}
\]
The equality is checked coefficientwise through the requested audit cutoff. This provides an independent check of the trivial column of the recurrence, not a replacement for the full nine-node recurrence.

## 5. Direct connection to T025

For a generic middle-degree block with \(p,q\ge1\), set \(m=p+q\) and
\[
\lambda_{p,q}=\frac{(2pq+p+q)^2}{4}.
\]
T025 showed that the positive singular-value line of \(D^\dagger D\) carries the full \(SU(2)\)-module \(V_m\); its exact block is scalar on that representation. Therefore the \(\rho_i\)-isotypic multiplicity of this positive eigenvalue is exactly
\[
\boxed{n_i(p+q).}
\]
The zero multiplicity line has the same decomposition. For the scalar quotient sector use \(n_{\mathbf1}(m)\); for an associated-bundle/twisted sector use the corresponding \(n_i(m)\). No factor \(d_i\) is to be inserted again: \(n_i\) already counts copies, and the eigenspace dimension is \(d_i n_i\).

This completes the representation multiplicity input for the generic T025 block. It does not by itself complete the zeta-regularized determinant or analytic torsion: the remaining spectral families, boundary sectors, grading weights, and the exact convention match from T021–T024 must still be assembled.

## 6. Audit and acceptance criteria

Run:
```bash
python audits/t026_mckay_e8_multiplicities.py --max-degree 120 --json
```
The script checks:

1. \(Ad=2d\), \(\sum_i d_i^2=120\), and \(\sum_i d_i=30\);
2. the recurrence (2) at every degree;
3. nonnegative integral multiplicities;
4. the dimension identity (3);
5. central-parity support (even/odd sectors);
6. the independent Hilbert-series coefficients (4);
7. selected decompositions including \(m=12\).
