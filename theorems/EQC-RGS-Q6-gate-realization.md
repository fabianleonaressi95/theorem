# EQC–RGS–Q6: exact gate realization of the induced geometric subgroup

**Classification:** exact finite combinatorial identification, with exhaustive finite verification of the seed action and its qutrit gate realization. This is a symmetry representation result, not a physical law or a quantum-speedup claim.

## 1. Fixed conventions

The RGS seed is taken in exactly the ordering used by
\`audits.morphodynamics.q6_mqm_symmetry.rgs_seed_coordinates()\`: eight orbit representatives, followed by sign triples in lexicographic product order. The Q6 vertex label is the resulting integer index \(v\in\{0,\ldots,63\}\), with bit \(i\) given by \((v\gg i)\mathbin{\&}1\).

For EQC the stored qutrit digits are
\[
d(-1)=0,\qquad d(0)=1,\qquad d(+1)=2.
\]
The binary Q6 sector \(\{0,+1\}^6\) is therefore the six-qutrit basis sector with digits in \(\{1,2\}\) at every position. Digit 0 is excluded.

## 2. The 16-element subgroup in Q6 coordinates

Reconstructing all 48 signed-coordinate permutations of the RGS seed and retaining exactly those that preserve the canonical Q6 adjacency gives 16 actions. In the established integer labels these are precisely:
- the eight independent translations generated by flipping Q6 bits 0, 1 and 2;
- those same eight translations followed by the simultaneous coordinate permutation
  \[
  (0\ 1)(3\ 4),
  \]
  with bits 2 and 5 fixed.

Equivalently, the group is generated by
\[
a_0:v\mapsto v\oplus1,\quad
a_1:v\mapsto v\oplus2,\quad
a_2:v\mapsto v\oplus4,
\]
and the coordinate permutation \(s\) with output bit order
\[
(1,0,2,4,3,5).
\]
Here \(s^2=1\), \(sa_0s=a_1\), \(sa_1s=a_0\), and \(s\) commutes with \(a_2\). Thus
\[
G_{\mathrm{RGS,Q6}}\cong C_2\times(C_2^2\rtimes C_2)
\cong C_2\times\operatorname{Dih}(4),
\qquad |G_{\mathrm{RGS,Q6}}|=16,
\]
where \(\operatorname{Dih}(4)\) is the order-eight symmetry group of a square.

The identification is tied to the repository's exact seed order and Q6 labels. In particular, the first three Q6 bits encode the three sign choices in the seed; the RGS Cartesian axes \(x,y,z\) correspond respectively to Q6 bits 2,1,0 under this ordering. This is not a freely interchangeable bit convention.

## 3. Realization using existing EQC instructions

A Q6 bit flip must exchange the two retained qutrit digits 1 and 2 while fixing the excluded digit 0. The correct local permutation is
\[
(0,1,2)\mapsto(0,2,1),
\]
implemented by the existing instruction \`P qN 0 2 1\`.

It is **not** the existing \`INV\` instruction: \`INV\` swaps stored digits 0 and 2, so it sends one retained binary level outside the Q6 sector. Nor is the ternary cyclic \`X\` gate suitable: it cycles all three levels.

The four group generators are represented by these existing EQC programs:

| Q6/RGS generator | EQC source |
|---|---|
| flip bit 0 | \`P q0 0 2 1\` |
| flip bit 1 | \`P q1 0 2 1\` |
| flip bit 2 | \`P q2 0 2 1\` |
| paired coordinate swap | \`SWAP q0 q1\` followed by \`SWAP q3 q4\` |

No new language opcode is required. Each instruction is a reversible monomial unitary on the full six-qutrit Hilbert space, and the generated subgroup preserves the 64-dimensional Q6 computational-basis sector.

## 4. Coupling to the MQM reference configuration

For a fixed reference edge vector \(x_*\in\mathbb R^{192}\), the geometric subgroup of the coupled RGS–Q6–MQM model is
\[
G_{\mathrm{RGS,MQM}}(x_*)=
G_{\mathrm{RGS,Q6}}\cap\operatorname{Stab}_{\operatorname{Aut}(Q6)}(x_*).
\]
The exact finite audit gives:
- uniform \(x_*\): order 16;
- six distinct direction-dependent edge values: order 8 (the three bit translations survive; the paired coordinate permutation does not);
- 192 pairwise distinct edge values: order 1.

These are stabilizer results for the stated reference patterns, not a calibration of the physical MQM model. The actual order remains conditional on the actual \(x_*\).

The standard-library audit:
1. reconstructs the 48 RGS signed-coordinate actions using the existing canonical seed routine;
2. independently generates the subgroup from four Q6 generators;
3. verifies exact equality of the two 16-element permutation sets;
4. checks Q6 adjacency preservation;
5. runs each EQC instruction program on all 64 Q6 basis states and checks the resulting vertex permutation;
6. verifies the three reference-stabilizer orders above.
