# T088 — Q-ball panel tangent frames, seam transport and geometry-induced anisotropy

**Date:** 11 November 2026  
**Status:** explicit geometric construction and finite-dimensional identities. Numerical audit script supplied; execution and calibration remain pending.

**Dependencies:** T080, T086, T087; `models/football_shell.py`.

## 1. Geometric data and panel frames

Let \(X:\mathcal V\to\mathbb R^3\) be the Q-ball shell embedding generated by `build_football_shell`. Each panel \(p\) has an ordered polygonal boundary and centroid \(c_p\). Define its outward unit normal by the oriented polygon area vector
\[
n_p=\frac{\sum_{a}(X_a-c_p)\times(X_{a+1}-c_p)}
{\left|\sum_{a}(X_a-c_p)\times(X_{a+1}-c_p)\right|}.
\]
Choose an orthonormal tangent frame \(Q_p=(e_{p,1},e_{p,2})\in\mathbb R^{3\times2}\) with
\[
Q_p^TQ_p=I_2,\qquad Q_p^Tn_p=0.
\]
The choice of the first tangent axis is a chart gauge. No physical result may depend on it.

The implementation uses the existing panel-frame construction in `models/football_shell.py::_panel_frame` (with material angle zero) and records the frame explicitly rather than assigning independent Cartesian unknowns to every panel.

## 2. A seam transition from the embedding

For a physical seam shared by panels \(p\) and \(q\), let \(R_{pq}\in SO(3)\) be the shortest proper rotation taking \(n_p\) to \(n_q\). If \(n_p\) and \(n_q\) are not antipodal, set
\[
a=n_p\times n_q,\quad s=|a|,\quad c=n_p\cdot n_q,
\]
\[
R_{pq}=I+[a]_\times+\frac{[a]_\times^2}{1+c}
\]
when \(s>0\); when \(s=0,c=1\), set \(R_{pq}=I\). The antipodal case is excluded for adjacent outward panels of this shell and must be handled explicitly if encountered.

The induced tangent-frame transition is
\[
\boxed{U_{pq}=Q_q^TR_{pq}Q_p\in O(2).}
\]
It maps components in the \(p\)-frame to components in the \(q\)-frame. Since \(R_{pq}\) maps \(n_p\) to \(n_q\), \(U_{pq}\) is orthogonal up to numerical roundoff. The reverse transition is \(U_{qp}=U_{pq}^T\).

Under independent chart rotations \(Q'_p=Q_pS_p\), \(S_p\in O(2)\),
\[
U'_{pq}=S_q^TU_{pq}S_p.
\]
This is the required bundle covariance. It is not an arbitrary identification of panel Cartesian coordinates.

## 3. Holonomy on the panel adjacency graph

The panel adjacency graph has one vertex per polygonal panel and one edge per physical seam. For an oriented cycle
\[
p_0\to p_1\to\cdots\to p_m=p_0,
\]
define the cycle holonomy
\[
\mathcal H_\gamma
=U_{p_{m-1}p_m}\cdots U_{p_1p_2}U_{p_0p_1}.
\]
It is an endomorphism of the initial tangent-frame fibre. Under a chart change at \(p_0\), it is conjugated:
\[
\mathcal H'_\gamma=S_{p_0}^T\mathcal H_\gamma S_{p_0}.
\]
Thus its eigenvalues, trace and rotation angle are gauge invariant.

This panel-graph holonomy is a discrete connection observable. It is not automatically equal to the integrated smooth Gaussian curvature: that comparison requires a refinement/convergence argument and a specified connection discretization.

## 4. Anisotropy derived from a declared geometric scalar field

The shell generator already provides the cubic harmonic
\[
H_4(n)=n_1^4+n_2^4+n_3^4-\frac35,\qquad |n|=1.
\]
Its spherical gradient is
\[
\nabla_{S^2}H_4(n)
=4\left((n_1^3,n_2^3,n_3^3)-H_4^{\,0}(n)n\right),
\quad H_4^{\,0}(n)=\sum_i n_i^4.
\]
The subtraction is the radial projection; the gradient is tangent to the sphere. At a panel direction \(\hat c_p=c_p/|c_p|\), set
\[
g_p=Q_p^T\nabla_{S^2}H_4(\hat c_p)\in\mathbb R^2.
\]
When \(g_p\ne0\), let \(\hat g_p=g_p/|g_p|\). Define the dimensionless geometric anisotropy tensor
\[
\boxed{A_p(\alpha)=I_2+\alpha\,\hat g_p\hat g_p^T,\qquad \alpha\ge0.}
\]
If \(g_p=0\), set \(A_p=I_2\) (the cubic harmonic supplies no preferred tangent direction there).

This construction derives the anisotropy axis from the existing cubic-sphere field rather than assigning a direction by hand. Its eigenvalues are \(1\) and \(1+\alpha\) when \(g_p\ne0\), so it is SPD for \(\alpha\ge0\). The parameter \(\alpha\) controls geometric anisotropy strength; it is not fitted to material data and is not yet a constitutive parameter.

A corresponding edge metric on a panel-side copy of an edge \(e\subset p\) is
\[
\boxed{M_{p,e}=\ell_e^{-1}A_p(\alpha).}
\]
The factor \(\ell_e^{-1}\) matches the explicit T086 graph metric convention; the tensor now distinguishes the tangent direction selected by \(H_4\). A different continuum scaling may be required for a refinement family.

Under a chart rotation, \(g'_p=S_p^Tg_p\) and \(A'_p=S_p^TA_pS_p\), so the quadratic edge energy is invariant. On a seam, the two panel-side tensors are compared only after transport:
\[
A_{q\leftarrow p}=U_{pq}A_pU_{pq}^T.
\]
The mismatch \(A_q-A_{q\leftarrow p}\) is a geometric anisotropy-jump observable, not itself a seam damage law.

## 5. Bulk, seam and curvature remain separate

The resulting data support three separate objects:
- panelwise bulk anisotropic edge metric \(M_{p,e}\);
- seam transport \(U_{pq}\) and seam trace jump in common frame;
- cycle holonomy \(\mathcal H_\gamma\).

No scalar penalty is imposed between them in this record. In particular, the construction does not identify anisotropy jumps with disarrangement, nor holonomy with dislocation density. A coupled energy would require independent constitutive assumptions and calibration.

## 6. Reproducibility and falsifiable checks

The accompanying script `scripts/audit_t088_qball_panel_geometry.py` is designed to report:
1. the 32 panel frames and 90 seam transitions;
2. the maximum orthogonality and reverse-transition residuals;
3. holonomy on every 3-cycle of the panel adjacency graph;
4. the eigenvalue bounds of all \(A_p(\alpha)\);
5. the chart-covariance residual under random \(O(2)\) frame changes;
6. the seam anisotropy mismatch after transport.

It uses \(\alpha=0.2\) only as a dimensionless demonstration value. The script is supplied but its output is not yet recorded here; no numerical pass is claimed.
