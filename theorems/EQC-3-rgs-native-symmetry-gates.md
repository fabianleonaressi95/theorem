# EQC-3 — Native RGS symmetry gates

**Classification:** exact finite group construction and permutation-unitary lift; finite tests compare the subgroup with the RGS seed. Not a universal physical symmetry claim.

## Label convention

T113-D uses big-endian six-bit labels. The first three bits select the eight RGS orbit representatives; the last three encode the signs of the spatial coordinates. In EQC, digits 0,1,2 encode symbols -1,0,+1. The Q6 alphabet {0,+1} is therefore represented by qutrit digits {1,2}.

## Generators

Let B_q exchange qutrit basis states |1> and |2>, fixing |0>. It is a unitary involution and preserves the binary subspace. The RGS/Q6 subgroup is generated by B_3, B_4, B_5 and SWAP_4,5.

In the existing local permutation syntax B_q is P q 0 2 1. The group is C2^3 semidirect C2, where the final C2 exchanges B_4 and B_5. Its order is 16 and it is isomorphic to C2 x D4.

## Exact gate semantics

Each B_q is a permutation matrix on one qutrit; SWAP_4,5 permutes the 729 computational basis states. Thus all generators are exactly unitary on the full six-qutrit Hilbert space. Their restrictions preserve the 64-dimensional Q6 subspace.

The implementation compares the full 16-element lifted permutation set with the subgroup induced by the 48 signed-coordinate transformations on the canonical RGS seed, retaining only those that preserve Q6 adjacency.

## Scope

These gates generate the RGS/Q6 subgroup, not all of Aut(Q6) or the ternary Hamming automorphism group. For a fixed MQM-1 reference vector x*, the native symmetry group is further intersected with Stab(x*). No quantum speedup or physical calibration is claimed.
