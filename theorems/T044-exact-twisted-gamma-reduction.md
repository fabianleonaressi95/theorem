# T044 — Exact algebraic evaluation of the eight twisted 2I Rumin torsions

## 1. Result

T043 reduced each isotypic Rumin torsion to a finite Hurwitz-zeta derivative and then to a finite Gamma product. T044 now removes the remaining Gamma values exactly.

For the nine irreducible representations, the exact results are

| Sector | Exact torsion |
|---|---:|
| 1 | 2 pi^2 / 15 |
| 2 | (3 - sqrt(5))/4 |
| 2' | (3 + sqrt(5))/4 |
| 3 | 1 - sqrt(5)/5 |
| 3' | 1 + sqrt(5)/5 |
| 4 | 5/3 |
| 4' | 1 |
| 5 | 3/2 |
| 6 | 2 |

Thus all eight nontrivial twisted-sector torsions lie in Q(sqrt(5)) or Q. Unlike the decimal recognition in T043, these identities are obtained by exact Gamma recurrence and Euler reflection, followed by exact cyclotomic trigonometric reduction.

## 2. Exact starting point

For each sector rho, T043 gives

    log T_rho =
      sum_(n<c) d_(n,rho) [log(4)-2log(n)]
      + sum_(r mod 60) e_(r,rho) [
          (log(4)-2log(60))(1/2-n_r/60)
          + 2log Gamma(n_r/60) - log(2pi)
        ].

The integers d_(n,rho), e_(r,rho), and the first representatives n_r are computed from the exact Molien numerator and the polynomial
P_rho(t)=(1-t^60)(t^2-1)(A_rho(t)-b_(0,rho)).

No numerical fitting or PSLQ is used in T044.

## 3. Gamma recurrence and reflection

Write n_r=60q_r+r with 1<=r<=60. The recurrence gives

    Gamma(n_r/60)
      = [product_(j=0)^(q_r-1) (r/60+j)] Gamma(r/60).

Every bracket is rational. The T043 coefficient table has the exact complementary-residue symmetry

    e_(r,rho)=e_(60-r,rho), 1<=r<=29.

Euler reflection then gives

    Gamma(r/60) Gamma(1-r/60)
      = pi / sin(pi*r/60).

The r=30 term uses Gamma(1/2)^2=pi; r=60 uses Gamma(1)=1. The pi powers cancel in every nontrivial sector. Consequently each nontrivial torsion is a rational prefactor times a finite product of rational-angle sine powers.

## 4. Explicit sine products

The exact expressions obtained from the recurrence and reflection steps are listed below. In each expression, sin(k) abbreviates sin(pi*k/60).

    T_2  = 4 *
      [sin(1)^2 sin(11)^2 sin(19)^2 sin(29)^2] /
      [sin(3)^2 sin(15)^2 sin(27)^2]
      = (3-sqrt(5))/4.

    T_2' = 4 *
      [sin(7)^2 sin(13)^2 sin(17)^2 sin(23)^2] /
      [sin(9)^2 sin(15)^2 sin(21)^2]
      = (3+sqrt(5))/4.

    T_3  = 8 *
      [sin(2)^2 sin(10)^2 sin(18)^2 sin(22)^2] /
      [sin(4)^2 sin(16)^2 sin(24)^2]
      = 1-sqrt(5)/5.

    T_3' = 8 *
      [sin(6)^2 sin(10)^2 sin(14)^2 sin(26)^2] /
      [sin(8)^2 sin(12)^2 sin(28)^2]
      = 1+sqrt(5)/5.

    T_4  = 16 *
      [sin(6)^2 sin(12)^2 sin(18)^2] /
      [sin(10)^2 sin(20)^2 sin(24)^2]
      = 5/3.

    T_4' = 16 *
      [sin(3)^2 sin(9)^2 sin(21)^2] /
      [sin(5)^2 sin(25)^2 sin(27)^2]
      = 1.

    T_5  = 32 *
      [sin(4)^2 sin(8)^2 sin(16)^2 sin(28)^2] /
      [sin(6)^2 sin(18)^2 sin(20)^2]
      = 3/2.

    T_6  = 64 sin(5)^2 sin(15)^2 sin(25)^2
      = 2.

These are identities in the real cyclotomic field generated by the 60th roots of unity. They reduce to Q(sqrt(5)) because the expressions are invariant under the relevant Galois conjugations. The exact symbolic verification is implemented in the accompanying module; it compares algebraic expressions with zero residual, not floating-point approximations.

The trivial sector is retained as the T042 identity T_1=2pi^2/15.

## 5. Regular-representation product

The regular representation contains dim(rho) copies of each irrep. Using the exact sector values,

    product_rho T_rho^(dim rho) = 16 pi^2.

This is now an exact identity, not merely the high-precision consistency check reported in T043. It agrees with the covering-sphere volume in Kitaoka's normalization.

## 8. Scope boundary

T044 proves the algebraic evaluation of the *alternating* torsion in every twisted isotypic sector. It does not construct separate meromorphic continuations of the degree-zero and degree-one spectral zeta functions. Their individual determinants require a separate analytic continuation of the unreduced double spectral sums; cancellation in the alternating combination cannot be used to infer either derivative separately.
