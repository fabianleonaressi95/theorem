# T118 — Gauge covariance of path transport and Wilson holonomy on a finite graph

**Classification:** exact algebraic theorem for arbitrary finite graphs with SU(2) link variables. The Möbius six-face audit is a deterministic numerical instance, not the proof.

## 1. Data and conventions

Let \(\Gamma=(V,E)\) be a finite graph. For each oriented edge \(u\to v\), assign \(U_{uv}\in SU(2)\), with
\[
U_{vu}=U_{uv}^{\dagger}.
\]
At every vertex choose \(G_v\in SU(2)\) and transform links by
\[
U^G_{uv}=G_vU_{uv}G_u^\dagger.
\]
For a path \(p=(v_0,v_1,\ldots,v_n)\), define the column-vector transporter with later links multiplying on the left:
\[
P_U(p)=U_{v_{n-1}v_n}\cdots U_{v_1v_2}U_{v_0v_1}.
\]

## 2. Theorem

For every path p,
\[
\boxed{P_{U^G}(p)=G_{v_n}P_U(p)G_{v_0}^{\dagger}.}
\]
For a closed path based at v_0, its holonomy transforms by conjugation:
\[
\boxed{H_{U^G}(p)=G_{v_0}H_U(p)G_{v_0}^{\dagger}.}
\]
Consequently the Wilson trace is gauge invariant:
\[
\boxed{\operatorname{tr}H_{U^G}(p)=\operatorname{tr}H_U(p).}
\]
For SU(2), this trace is real, and the normalized Wilson observable \(\frac12\operatorname{tr}H_U(p)\) lies in [-1,1].

### Proof

For n=1 the path identity is the link transformation law. Suppose it holds for a path ending at v_{n-1}. Appending the last edge gives
\[
\begin{aligned}
P_{U^G}(v_0,\ldots,v_n)
&=U^G_{v_{n-1}v_n}P_{U^G}(v_0,\ldots,v_{n-1})\\
&=G_{v_n}U_{v_{n-1}v_n}G_{v_{n-1}}^\dagger
  G_{v_{n-1}}P_U(v_0,\ldots,v_{n-1})G_{v_0}^\dagger\\
&=G_{v_n}P_U(p)G_{v_0}^\dagger.
\end{aligned}
\]
Induction proves the open-path identity. If \(v_n=v_0\), this is conjugation at the base vertex. Trace invariance follows from cyclicity of trace.

Every SU(2) matrix has eigenvalues \(e^{i\theta},e^{-i\theta}\), so its trace is \(2\cos\theta\in[-2,2]\). This proves reality and the normalized bound. \(\square\)

## 3. Application to the Möbius subcomplex

Take \(\Gamma=K^{(1)}\), the 18-edge 1-skeleton of T117, and assign independent SU(2) matrices to one orientation of each edge. The reverse edge is its Hermitian conjugate. Then the theorem applies to every path in K, including all six oriented face boundaries.

The source audit \`src/mobius_gauge_audit.py\` uses seed 20261103, tolerance \(10^{-10}\), tests six face loops and their open prefixes, and checks reverse-link consistency. The test suite also checks repeatability for seed 17 and JSON export for seed 1234. These are finite numerical checks of the general theorem; no particular residual values are asserted in this record.

## 4. Separation of internal gauge and base orientation

The SU(2) gauge matrices act on the internal \(\mathbb C^2\) fibres. The orientation-reversing face-transition data of the non-orientable base are separate. The path-covariance theorem neither constructs nor requires a Pin lift of the Möbius tangent bundle.
